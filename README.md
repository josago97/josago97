## El evento histórico de hoy
El 31 de octubre de 1969 se envió el primer mensaje entre dos nodos de ARPANET (UCLA y Stanford), la red precursora de Internet, aunque el sistema se cayó tras teclear solo las letras "LO" de "LOGIN".

## El temazo de hoy
#### [Michael Jackson - Thriller](https://www.youtube.com/watch?v=sOnqjkJTMaA)
Lanzado como sencillo el 31 de octubre de 1983, se convirtió en el himno definitivo de Halloween gracias a su icónico videoclip dirigido por John Landis. La canción fusiona funk y pop con una narrativa de terror cinematográfica, incluyendo la legendaria locución de Vincent Price.
