## El evento histórico de hoy
El 5 de agosto de 1995, Microsoft lanzó Internet Explorer 1.0, su primer navegador web, que fue incluido como un complemento gratuito en Windows 95 para competir con Netscape Navigator.

## El temazo de hoy
#### [Wham! - Freedom](https://www.youtube.com/watch?v=kZl0AzHMI_Q)
Lanzado originalmente en 1984, 'Freedom' fue relanzado como single el 5 de agosto de 1985. Este tema energético de pop dance muestra el característico sonido ochentero de Wham! con sintetizadores brillantes y la poderosa voz de George Michael. La canción se convirtió en otro éxito comercial que consolidó su fama internacional.
