## El evento histórico de hoy
El 19 de octubre de 1985 se lanzó al mercado el Intel 80386 (i386), el primer microprocesador x86 de 32 bits que permitió la multitarea protegida y sentó las bases para los sistemas operativos modernos como Windows 3.x y Linux.  
Su arquitectura introdujo la paginación de memoria y el modo virtual 8086, revolucionando el desarrollo de software para PC.
