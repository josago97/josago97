## El evento histórico de hoy
El 4 de agosto de 1996, Hotmail, el primer servicio de correo electrónico web gratuito y masivo, fue lanzado oficialmente, revolucionando la comunicación en línea.

## El temazo de hoy
#### [Avril Lavigne - Complicated](https://www.youtube.com/watch?v=5NPBIwQyPWE)
Este éxito de 2002 se convirtió en el himno del pop punk adolescente, criticando la falsedad y la hipocresía en las relaciones personales. Con su actitud rebelde y melodías pegadizas, lanzó a Avril Lavigne al estrellato internacional y definió el sonido de una generación.
