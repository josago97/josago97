## El evento histórico de hoy
El 16 de octubre de 1956 se ejecuta el primer compilador FORTRAN en un IBM 704, permitiendo por primera vez programar en lenguaje de alto nivel en lugar de código máquina.  
Este hito, liderado por John Backus, redujo drásticamente los errores y el tiempo de desarrollo de software científico.

## El temazo de hoy
#### [Whitney Houston - I Will Always Love You](https://www.youtube.com/watch?v=3JWTaaS7LdU)
Este poderoso balada, lanzada como single el 16 de octubre de 1992, se convirtió en la canción más vendida de la historia por una artista femenina. La interpretación de Houston para la película 'El guardaespaldas' definió una época y sigue siendo un referente vocal indiscutible.
