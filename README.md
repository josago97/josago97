## El evento histórico de hoy
El 5 de septiembre de 1983, Richard Stallman anunció públicamente el proyecto GNU para crear un sistema operativo libre tipo Unix, sentando las bases del movimiento de software libre y la posterior licencia GPL.

## El temazo de hoy
#### [Bobby McFerrin - Don't Worry, Be Happy](https://www.youtube.com/watch?v=d-diB65scQU)
Es un tema a capela optimista que se convirtió en himno antiestrés global tras su uso en la campaña de George H. W. Bush. Ganó el Grammy a la Canción del Año en 1989 demostrando que la voz humana basta para crear un éxito atemporal.
